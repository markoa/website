AI is writing code faster than teams can review, test, and deploy it. SuperPlane is built for orchestrating everything after code.

This week we're opening the SuperPlane Cloud beta and walking through the platform day by day: the execution engine, the agent, coding agent integrations, and [SuperPlane Apps](https://docs.superplane.com/concepts/superplane-apps/).

We announced SuperPlane as [an open source project in January](/signals/superplane-is-open-source); the managed cloud is the easiest way to try the parts that need real infrastructure: sandboxed Python and TypeScript runners, and the built-in AI agent.

Launch Week starts today with a [blog post](https://superplane.com/blog/superplane-cloud-beta/) and [YouTube livestream](https://www.youtube.com/live/iMC2Uk2gVLg) (edit: livestream moved to tomorrow). [Full schedule on the SuperPlane blog](https://superplane.com/blog/superplane-beta-launch-week/).
